# FnWave mainland website

Public static website served by GitHub Pages at https://cn.getfnwave.com.

Pages publishes `main` / `docs` automatically after each commit. The private software repository, license console, API, payment callbacks, and secrets are not part of this repository. Public-page source is maintained in the private repository; this repository contains only the audited browser build. Downloads and model endpoints remain unchanged.

Branding, particle/avatar animations, bilingual pages (English by default), and 2× looping demo videos are preserved.
