Feature overview

Chat handles requests, Sounds handles assets, and Projects handles saved work. Plugins and Tools manage plugins and local models.

01

Choose an entry point by task

Find a sound
Search in Sounds. Use Smart Search for a listening description, or Find Similar when you have reference audio.
Build a layered effect
Choose Sound Composition in Chat, describe the source, action, and layers, then audition the result.
Edit a project in batches
Select REAPER in Chat and say exactly what is selected and what should change.
Find a sound you made before
Find the project in Projects, listen to its preview, then use Load Selection to return to the excerpt.
Find a plugin quickly
Filter Plugins by maker, format, or purpose. Drag it to REAPER or build an effect chain first.
02

How the modules work together

Sounds provides local assets for Chat’s search and composition tasks. Projects makes your existing work easier to find and audition. REAPER Bridge sends actions and results into REAPER; the app does not replace your DAW.
