System requirements

The current desktop build targets Windows. This is a provisional support baseline, not a guarantee for every hardware combination.

01

Hardware support baseline

A complete minimum hardware specification has not been formally finalized. These figures come from current code, installer size, and runtime testing for pre-release validation.

System
Minimum: Windows 10 22H2 64-bit. Recommended: Windows 11 64-bit.
CPU
Minimum: x86-64, 4 cores. Recommended: Intel i5 / Ryzen 5 from the last 6 years, 6+ cores.
Memory
Minimum: 8 GB. Recommended: 16 GB.
Disk
SSD with at least 5 GB free for installation; 10 GB or more recommended.
GPU
No dedicated GPU required. The current production runtime uses the CPU by default.
Display
Minimum: 1366×768 at 100% scaling. Recommended: 1920×1080.
02

What else is needed?

  • •REAPER with a working REAPER Bridge connection for automation, preview export, and transfers.
  • •Your own API Key only when using online AI features.
  • •Internet access for online AI, license verification, and model downloads. These are not fully offline features.
03

Allow extra space for assets and models

The 5 GB figure covers installation, not your sound libraries, project previews, or additional models. Large libraries and local models need more disk space. Model requirements differ; check their memory, hardware, and runtime assessment in Tools.
