Plugins: browsing and effect chains

Browse plugins installed in REAPER, inspect screenshots, and assemble a chain before importing it.

01

Scan plugins and capture screenshots

  1. 01In Preferences → Plugins, check the REAPER path and capture settings. Keep the required connection working.
  2. 02In Plugins, press the camera button, Capture missing. It scans for new plugins, then fills missing screenshots. Wait for completion.
  3. 03Right-click a plugin to recapture an incorrect image. If automatic capture fails, upload an image manually.
Scanning discovers installed plugins; it does not buy or install them. Do not close the REAPER process needed for capture.
02

Narrow the list

Search by name or open filters. Combine device category, function, format, maker, and source—for example, Effect plus a particular maker. Favorites keeps your regular choices nearby; Recent shows recent use; Hidden shows hidden entries.

Filters list choices present in your scanned results. Clear them to restore the full list. Hiding a plugin does not uninstall it.
03

Use one plugin

  1. 01Select a plugin to inspect it, or switch between card and list views.
  2. 02Drag it onto a supported track or Item target in REAPER.
  3. 03Check the instance and parameters in REAPER. The app’s screenshot is not an interactive plugin window.
04

Import an effect chain

  1. 01Add the plugins you need to the effect chain at the bottom.
  2. 02Drag to reorder and remove unwanted entries. Clear only empties the pending chain.
  3. 03Select the target in REAPER, click Import, confirm the target and order, then audition the result.
Plugin order changes the sound. Import changes the target chain in REAPER; use a test track if you are unsure.
